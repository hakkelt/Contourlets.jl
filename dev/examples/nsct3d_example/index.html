3-D NSCT Example

The 3-D Nonsubsampled Contourlet Transform decomposes a volume into a coarse residual plus 3 * 2^L directional subbands per scale, all at the input size. Like its 2-D counterpart it is exactly equivariant under circular shifts.

using Contourlets, Random

vol    = randn(Xoshiro(1), 32, 32, 32)
params = ContourletParams3D(J = 2, L_array = [1, 2])
ContourletParams3D(J=2, L_array=[1, 2], order=12, …)

Variant 1 — Allocating

c   = nsct3d_forward(vol, params)
rec = nsct3d_inverse(c, params)

println("PR error: ", maximum(abs, rec .- vol))
println("coarse: ", size(c.coarse))
for j in 1:params.J
    println("scale $j: $(length(c.subbands[j])) subbands of $(size(c.subbands[j][1]))")
end
@assert maximum(abs, rec .- vol) < 1e-12
PR error: 2.220446049250313e-15
coarse: (32, 32, 32)
scale 1: 6 subbands of (32, 32, 32)
scale 2: 12 subbands of (32, 32, 32)

Note how fast the coefficient count grows: 3 * 2^L subbands per scale. That is the price of shift invariance, and it is why the streaming form below exists.

Variant 2 — Workspace (for iterative algorithms)

Build the plans once and reuse them. This is the entry point for reconstruction loops, where the transform is applied hundreds of times to the same volume size.

ws  = make_nsct3d_workspace(params, size(vol), Float64)
out = similar(vol)

for _ in 1:3
    coeffs = nsct3d_forward(vol, params; workspace = ws)
    nsct3d_inverse!(out, coeffs, params; workspace = ws)
end
println("PR error with workspace: ", maximum(abs, out .- vol))
@assert maximum(abs, out .- vol) < 1e-12
PR error with workspace: 2.220446049250313e-15

Variant 3 — Streaming (the one to use at working sizes)

At 256³ Float32 a single subband is 64 MB, so J = 3 with L = [2, 2, 3] would materialise 49 volumes — 3.1 GB — before you do anything with them. The streaming form calls back once per subband and reuses one buffer, so it holds two volumes plus the plans.

energy = Dict{Tuple{Int, Int}, Float64}()

coarse = nsct3d_forward(vol, params) do j, k, band
    # `band` is valid only until this callback returns — copy or reduce here.
    energy[(j, k)] = sum(abs2, band)
end

println("coarse energy:      ", round(sum(abs2, coarse), digits = 2))
println("directional energy: ", round(sum(values(energy)), digits = 2))
coarse energy:      495.32
directional energy: 31442.44

The inverse streams too: f(j, k) returns each subband on demand, so a caller that keeps coefficients on disk — or regenerates them — never holds the full set.

r = nsct3d_inverse(c.coarse, params) do j, k
    c.subbands[j][k]
end
println("streaming inverse PR error: ", maximum(abs, r .- vol))
@assert maximum(abs, r .- vol) < 1e-12
streaming inverse PR error: 2.220446049250313e-15

Shift invariance

s = (3, -2, 5)
a = nsct3d_forward(vol, params)
b = nsct3d_forward(circshift(vol, s), params)

err = maximum(
    maximum(abs, b.subbands[j][k] .- circshift(a.subbands[j][k], s))
        for j in 1:params.J for k in eachindex(a.subbands[j])
)
println("shift equivariance error: ", err)
@assert err < 1e-10
shift equivariance error: 8.881784197001252e-16

Directional selectivity

A plane wave lands in the subband whose wedge contains its frequency vector. Here the frequency is steepest along axis 3, so the winning subband belongs to the third hourglass.

n = 32
k = (2, 5, 13)
wave = [
    cospi(2 * (k[1] * (i - 1) + k[2] * (j - 1) + k[3] * (l - 1)) / n)
        for i in 1:n, j in 1:n, l in 1:n
]

fb = make_nsdfb3d((n, n, n), Float64; levels = 4, transition = 0.5)
e  = zeros(nsdfb3d_nsubbands(fb))
nsdfb3d_decompose(wave, fb) do idx, band
    e[idx] = sum(abs2, band)
end

best = argmax(e)
hourglass, p, q = nsdfb3d_subband_triple(fb, best)
println("winning subband $best: hourglass $hourglass, wedge ($p, $q)")
println("its share of the energy: ", round(e[best] / sum(e), digits = 3))
@assert hourglass == 3
winning subband 43: hourglass 3, wedge (3, 3)
its share of the energy: 0.742

Complex volumes

Complex data is filtered as two real passes through the identical kernel, so the transform is exactly real-linear: T(x + i·y) == T(x) + i·T(y), bit for bit. That makes it a usable correctness check on your own code built on top.

xr = randn(Xoshiro(2), 16, 16, 16)
xi = randn(Xoshiro(3), 16, 16, 16)
p  = ContourletParams3D(J = 1, L_array = [1])

cc = nsct3d_forward(complex.(xr, xi), p)
cr = nsct3d_forward(xr, p)
ci = nsct3d_forward(xi, p)

println(
    "linearity error: ",
    maximum(abs, cc.subbands[1][1] .- complex.(cr.subbands[1][1], ci.subbands[1][1]))
)
linearity error: 0.0

Decimated: the surfacelet transform

The NSCT3D keeps every subband at full size. The surfacelet transform stores each one at its own reduced resolution instead, giving up shift invariance for a smaller coefficient set. Reconstruction is still exact.

sp = SurfaceletParams3D(J = 2, L_array = [1, 1])
pl = make_surfacelet3d(sp, size(vol), Float64)

sc = surfacelet3d_forward(vol, sp; plan = pl)
sr = surfacelet3d_inverse(sc, sp; plan = pl)

println("PR error: ", maximum(abs, sr .- vol))
println("redundancy: ", round(surfacelet3d_redundancy(pl), digits = 2))
println("coarse subband: ", size(sc.coarse), " from a ", size(vol), " volume")
println("scale 1 subband: ", size(sc.subbands[1][1]))
println("scale 2 subband: ", size(sc.subbands[2][1]))
@assert maximum(abs, sr .- vol) < 1e-11
PR error: 1.7763568394002505e-15
redundancy: 7.67
coarse subband: (11, 11, 11) from a (32, 32, 32) volume
scale 1 subband: (32, 31, 32)
scale 2 subband: (21, 21, 21)

Note the sizes: coarser scales cover smaller frequency shells and are stored on correspondingly smaller grids. See 3-D Surfacelets for the transform on its own — atoms, redundancy trade-offs, directional selectivity — and Theory — 3-D for how far this decimation goes and where it stops short of the reference construction.
